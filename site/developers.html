WIZ API

ממשק REST פתוח לחיפוש ולגישה לכל תוכן הארכיון: גליונות, תוכני עניינים, טקסט מלא של כל עמוד (OCR), תמונות וקובצי PDF. כל התשובות ב-JSON, בקידוד UTF-8, ומותרות לקריאה מכל אתר (CORS). אין צורך במפתח.

הטקסט זוהה אוטומטית מסריקות ועשוי להכיל שגיאות. כל הקישורים בתשובות הם כתובות מלאות.

נקודות קצה

GET/api/issues
רשימת כל הגליונות: מספר, תאריך, מספר עמודים, כריכה, PDF וקישורים.
yearסינון לפי שנה (רשות)
GET/api/issues/{number}
גליון אחד: פרטים, תוכן העניינים (toc) ורשימת כל העמודים עם קישורים לתמונות (page_list).
GET/api/issues/{number}/pages/{page}
עמוד אחד לפי מספר העמוד המודפס: הטקסט המלא (text), הכתבה שהעמוד שייך לה (article), תמונה, תמונה מוקטנת, קישור ל-PDF בעמוד הנכון, וקישורים לעמוד הקודם והבא.
GET/api/search?q={query}
חיפוש בטקסט המלא של כל העמודים. מחזיר עמודים שמכילים את כל המילים, עם קטע טקסט, הכתבה, תמונה וקישורים. חיפוש מילה מוצא גם צורות ארוכות יותר וצורות עם אותיות שימוש (משחק ← "והמשחקים"). ביטוי מדויק: במירכאות.
qמילות החיפוש (חובה). למשל q="משחקי תפקידים" AD&D
from, toטווח שנים
sortrank (ברירת מחדל, הרלוונטי ביותר קודם) או issue (לפי סדר הגליונות)
limit, offsetעימוד (limit עד 100, ברירת מחדל 20). התשובה כוללת total ו-next
GET/api/articles
חיפוש בכתבות מתוכני העניינים (כ-3,000 פריטים).
qמילים בכותרת או במדור
sectionשם מדור מדויק (ראו /api/sections)
issue, from, toגליון מסוים / טווח שנים
limit, offsetעימוד (limit עד 500, ברירת מחדל 50)
GET/api/sections
כל המדורים בתוכני העניינים, עם מספר הכתבות והגליון הראשון והאחרון שבו הופיעו.

דוגמה

const r = await fetch("https://YOUR-SITE.pages.dev/api/search?q=" + encodeURIComponent("סוניק") + "&limit=5");
const { total, results } = await r.json();
for (const hit of results)
  console.log(hit.issue, hit.page, hit.date, hit.article?.title, hit.snippet, hit.url);
